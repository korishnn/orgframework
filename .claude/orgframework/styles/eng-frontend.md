# eng-frontend

**Summary:** Frontend Engineer builds responsive, accessible, and performant web applications and user interfaces that deliver the product experience to end users.

**Level:** IC
**Reports to:** Engineering Manager
**Region variants:** NA, EMEA, APAC, LATAM

## Responsibilities
- Develop responsive, accessible, and performant web applications using modern frontend frameworks
- Translate design mockups, wireframes, and prototypes from Figma/Sketch into production-quality code
- Implement client-side state management, data fetching, caching, and optimistic UI patterns
- Optimize frontend performance metrics including Largest Contentful Paint (LCP), First Input Delay (FID), and Cumulative Layout Shift (CLS)
- Write and maintain component libraries, design system integrations, and shared UI utilities
- Ensure cross-browser compatibility, progressive enhancement, and graceful degradation across devices
- Collaborate with backend engineers on API contract design and integration points
- Implement comprehensive frontend testing including unit, integration, visual regression, and end-to-end tests
- Participate in code reviews with attention to accessibility, performance, and code quality
- Build and maintain internal tooling, developer utilities, and frontend build configurations
- Contribute to technical documentation for component usage and development workflows
- Stay current with evolving web standards, browser APIs, and frontend ecosystem changes

## Core Competencies
- Expert-level proficiency in modern JavaScript/TypeScript, HTML5, and CSS3
- Deep experience with at least one major frontend framework (React, Vue, Angular, Svelte)
- Strong understanding of accessibility standards (WCAG 2.1/2.2, ARIA, semantic HTML)
- Experience with frontend testing tools (Jest, Vitest, Cypress, Playwright, Testing Library)
- Knowledge of build tools and module bundlers (Webpack, Vite, esbuild, TurboPack)
- Understanding of web performance profiling, Core Web Vitals, and optimization techniques
- Familiarity with state management patterns (Redux, Zustand, Pinia, Recoil, Jotai)
- Experience with CSS frameworks and methodologies (Tailwind, CSS Modules, CSS-in-JS, BEM)
- Knowledge of web security fundamentals (XSS, CSRF, CSP, CORS)
- Understanding of responsive and mobile-first design principles

## Tools & Technology
- Frameworks: React, Next.js, Vue, Nuxt, Angular, Svelte, SolidJS
- Languages: TypeScript, JavaScript, WASM
- Styling: Tailwind CSS, Styled Components, Emotion, CSS Modules, Sass
- Testing: Jest, Vitest, Cypress, Playwright, Storybook, Chromatic
- Build: Vite, Webpack, esbuild, Turborepo, Nx, PNPM
- Monitoring: Sentry, Datadog RUM, Lighthouse, Web Vitals

## KPIs & Success Metrics
- Core Web Vitals scores (LCP under 2.5s, FID under 100ms, CLS under 0.1)
- Page load time and Time to Interactive
- Test coverage percentage (unit, integration, E2E)
- Accessibility compliance score (WCAG AA/AAA)
- Bundle size budget adherence and tree-shaking effectiveness
- Bug escape rate and UI defect density
- Component reuse rate and design system adoption percentage

## Career Progression
- Junior (0-2 years): Builds UI components under guidance, fixes bugs, writes basic tests
- Mid (2-4 years): Independently implements feature-level work, optimizes performance, contributes to design system
- Senior (4-7 years): Leads frontend architecture decisions, drives performance initiatives, mentors juniors
- Staff (7-10 years): Shapes frontend strategy across teams, builds shared tooling, establishes best practices
- Principal (10+ years): Company-wide technical leadership, drives web platform vision, influences industry standards
- Typical progression: Junior to Mid 1-2 years, Mid to Senior 2-3 years, Senior to Staff 2-4 years

## Day-to-Day Workflow
- Daily standup to sync with the team on progress and blockers
- Sprint-based work in 1-2 week iterations with planning, grooming, and retrospectives
- Regular design reviews with UX designers to validate implementation fidelity
- Code reviews as a continuous part of the workflow, reviewing 2-4 PRs daily
- Weekly 1:1 with engineering manager for growth and project alignment
- Component development follows a pattern: design review, implementation, testing, documentation
- Performance monitoring reviews during sprint cycles to track key metrics
- Cross-team collaboration sessions for design system changes and API contract alignment

## Regional Nuances
- NA: Largest frontend job market with highest compensation; heavy React/TypeScript dominance; strong remote culture; emphasis on accessibility (ADA compliance)
- EMEA: Greater diversity of framework usage (more Vue.js in France, Angular in enterprise); stricter accessibility enforcement (EU Web Accessibility Directive); strong labor protections
- APAC: Fast-growing frontend communities in India and Southeast Asia; higher mobile-first focus; popularity of Vue.js in China; competitive salaries in Singapore and Tokyo
- LATAM: Growing remote talent pool serving US companies; React and React Native skills in high demand; time zone compatibility with NA; strong community in Brazil and Argentina

## Industry Variations
- SaaS: Complex data-rich interfaces, dashboard-heavy, real-time collaboration features, multi-tenant UI patterns
- Fintech: Data accuracy requirements, strict form validation, regulatory disclosures, transaction status displays
- E-commerce: Product discovery and search, cart and checkout flows, personalization, mobile-responsive critical
- Healthcare: HIPAA-compliant data display, patient portal interfaces, medical record visualization, accessibility critical
- Media/Entertainment: Content-rich experiences, video players, SSR/SSG for SEO, ad integration, progressive web apps

## Common Challenges
- Keeping up with the rapid pace of framework and tooling ecosystem changes
- Balancing rich user experiences with performance budgets across devices and network conditions
- Maintaining cross-browser consistency, especially with newer CSS and JS features
- Managing state complexity in large single-page applications with multiple data sources
- Ensuring accessibility compliance without slowing feature delivery
- Coordinating design and implementation across multiple teams and design system versions

## Key Regulations & Compliance
- WCAG 2.1/2.2 AA (accessibility, often contractual requirement)
- Section 508 for US federal government applications
- GDPR for cookie consent and user tracking in EMEA
- CCPA for California user data privacy
- ADA compliance for US accessibility requirements
- EU Web Accessibility Directive for European public sector
