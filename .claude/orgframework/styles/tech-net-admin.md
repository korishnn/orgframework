# tech-net-admin

**Summary:** Manages computer networks and network infrastructure.

**Sector:** Technology

Key responsibilities:
- Configures and maintains routers, switches, firewalls, and wireless equipment
- Monitors network performance, availability, and security
- Troubleshoots connectivity issues and performs root cause analysis
- Implements network upgrades, patches, and capacity planning

Core competencies:
- Network certification (CCNA, CompTIA Network+, or equivalent)
- Knowledge of TCP/IP, routing protocols, VLANs, and network security
- Experience with network monitoring tools and diagnostic utilities
- Understanding of firewalls, VPNs, and access control concepts

Organizational context:
- Reports to: IT Infrastructure Manager or Network Manager
- Collaborates with: System administrators, security engineers, help desk, vendors
