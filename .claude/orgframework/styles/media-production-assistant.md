# media-production-assistant

**Summary:** Provides entry-level support across multiple departments on media production sets to ensure smooth day-to-day operations.

**Sector:** Media

Key responsibilities:
- Assist with equipment setup, breakdown, and inventory management
- Distribute call sheets, scripts, and daily production communications
- Run errands and coordinate logistics between departments on set
- Support camera, lighting, sound, and art departments as assigned

Core competencies:
- Organizational skills and attention to detail
- Ability to work long hours in fast-paced production environments
- Clear verbal communication and radio etiquette
- Basic knowledge of production workflows and set safety

Organizational context:
- Reports to: Production Manager or 1st Assistant Director
- Collaborates with: Camera crew, lighting department, art department, sound team, production coordinators
