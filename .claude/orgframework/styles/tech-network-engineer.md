# tech-network-engineer

**Summary:** Designs, implements, and maintains computer networks including LAN, WAN, data center, and cloud networking infrastructure.

**Sector:** Technology

Key responsibilities:
- Design and deploy network topologies, routing, switching, and firewall architectures
- Monitor network performance, troubleshoot incidents, and optimize throughput
- Implement network security controls including ACLs, VPNs, and segmentation
- Automate network configuration and change management processes

Core competencies:
- Deep knowledge of routing protocols (BGP, OSPF, EIGRP) and switching technologies
- Hands-on experience with Cisco, Juniper, Arista, or equivalent platforms
- Network automation with Python, Ansible, or Terraform
- Understanding of load balancing, DNS, DHCP, and network monitoring tools

Organizational context:
- Reports to: Network Manager or IT Infrastructure Director
- Collaborates with: Systems administrators, security team, cloud engineers, data center ops, vendors
