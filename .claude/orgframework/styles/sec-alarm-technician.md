# sec-alarm-technician

**Summary:** Installs and maintains security alarm systems.

**Sector:** Security

Key responsibilities:
- Installs burglar alarms, fire alarms, CCTV systems, and access control equipment
- Configures and programs alarm panels, sensors, and monitoring connections
- Troubleshoots and repairs system faults and performs routine maintenance
- Inspects existing systems and recommends upgrades to meet client needs

Core competencies:
- Technical knowledge of security systems, wiring, and low-voltage installation
- Proficiency with alarm programming software and networking concepts
- Understanding of building codes and fire/life safety regulations
- Customer service skills for client education on system operation

Organizational context:
- Reports to: Alarm Operations Manager or Service Supervisor
- Collaborates with: Security sales reps, monitoring centers, electricians, building owners
