# tech-embedded-engineer

**Summary:** Develops software for embedded systems and microcontrollers that control hardware devices with resource constraints.

**Sector:** Technology

Key responsibilities:
- Write and debug firmware for microcontrollers and embedded processors
- Develop board support packages, device drivers, and hardware abstraction layers
- Optimize code for memory, power, and real-time performance constraints
- Collaborate with hardware engineers on schematic and PCB design decisions

Core competencies:
- Proficiency in C, C++, and assembly for embedded targets
- Experience with RTOS, bare-metal programming, and interrupt handling
- Understanding of digital electronics, schematics, and datasheet interpretation
- Debugging with oscilloscopes, logic analyzers, and JTAG/SWD probes

Organizational context:
- Reports to: Embedded Engineering Manager or Hardware Lead
- Collaborates with: Hardware engineers, firmware engineers, QA, systems engineering, product management
