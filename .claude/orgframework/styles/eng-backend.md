# eng-backend

**Summary:** Backend Engineer designs, builds, and maintains server-side logic, APIs, data services, and system integrations that power the product experience.

**Level:** IC
**Reports to:** Engineering Manager
**Region variants:** NA, EMEA, APAC, LATAM

## Responsibilities
- Design, develop, test, and deploy RESTful and GraphQL APIs that serve web and mobile clients with high performance and reliability
- Implement business logic, server-side application features, and data processing workflows
- Optimize database schemas, queries, and indexing strategies for performance at scale
- Write comprehensive unit, integration, contract, and end-to-end tests
- Participate in code reviews and architectural discussions to maintain code quality and consistency
- Document API contracts, system behavior, and data models using OpenAPI or equivalent specifications
- Troubleshoot production issues, debug distributed system failures, and support live services during incidents
- Design and implement event-driven architectures using message queues and stream processing
- Build and maintain integrations with third-party services and external APIs
- Implement security best practices including authentication, authorization, input validation, and data encryption
- Participate in agile ceremonies including sprint planning, standups, retrospectives, and demos
- Contribute to system design documents and engineering design reviews
- Mentor junior engineers through pairing, code reviews, and knowledge sharing sessions

## Core Competencies
- Strong programming skills in at least one of Python, Go, Java, TypeScript (Node.js), or Ruby
- Deep understanding of relational databases (PostgreSQL, MySQL) and NoSQL stores (Redis, MongoDB, DynamoDB)
- Knowledge of API design principles covering REST, GraphQL, gRPC, and WebSocket patterns
- Familiarity with message queuing and event streaming (Kafka, RabbitMQ, SQS, NATS)
- Understanding of caching strategies and technologies (Redis, Memcached, CDN)
- Proficiency with version control (Git) and collaborative development workflows (GitHub Flow, trunk-based)
- Knowledge of containerization and orchestration (Docker, Kubernetes) for local development and deployment
- Understanding of observability fundamentals (structured logging, metrics, distributed tracing)
- Experience with authentication and authorization patterns (OAuth2, JWT, RBAC, SAML)
- Strong debugging, problem-solving, and systems thinking skills

## Tools & Technology

## KPIs & Success Metrics
- API response latency (p50, p95, p99) and error rates
- Service uptime and availability percentage
- Deployment frequency and lead time for changes
- Code coverage percentage and test pass rate
- Sprint velocity and story point completion rate
- Production incident count and severity distribution
- API adoption rate and developer satisfaction scores

## Career Progression
- Junior (0-2 years): Implements well-scoped features under guidance, writes tests, learns system architecture patterns
- Mid (2-5 years): Independently delivers feature-sized changes, participates in design discussions, owns specific service areas
- Senior (5-8 years): Designs and leads complex feature initiatives, mentors others, drives engineering best practices
- Staff (8+ years): Influences architecture across multiple teams, sets technical direction, defines org-wide standards
- Principal (10+ years): Company-wide technical leadership, drives multi-year architecture strategy
- Typical progression: Junior to Mid 1-2 years, Mid to Senior 2-3 years, Senior to Staff 2-4 years

## Day-to-Day Workflow
- Daily standup to share progress, blockers, and plans with the team
- Sprint-based development with 1-2 week iterations, planning at the start, retro at the end
- Core working hours overlap for team collaboration with flexibility for deep work
- Code reviews performed daily as part of workflow (review 2-3 PRs per day)
- Weekly 1:1 with engineering manager for career development and project alignment
- Bi-weekly demo sessions to showcase completed work to stakeholders
- On-call rotation for production support (typically 1 week every 4-6 weeks)
- Documentation writes as part of each feature or system change

## Regional Nuances
- NA: Largest job market with highest compensation; strong culture of ownership and autonomy; remote-first roles common; emphasis on scalability and reliability
- EMEA: Stronger labor protections and standard 35-40 hour work weeks; works councils in Germany and France; higher adoption of Java and C# in enterprise companies; GDPR knowledge expected
- APAC: Fast-growing market with high demand in India, Singapore, and Japan; more hierarchical team structures; competitive compensation in Singapore and Tokyo; broader skillset expected at each level
- LATAM: Growing remote workforce serving US-based companies; strong Node.js and Python adoption; salary arbitrage creates cost-effective engineering hubs; time zone overlap with NA is an advantage

## Industry Variations
- SaaS: Multi-tenant architecture, API-first design, usage-based billing integration, and high uptime requirements
- Fintech: Transactional integrity, audit logging, strong consistency requirements, PCI-DSS compliance, real-time processing
- Healthcare: HIPAA compliance, HL7/FHIR interoperability standards, PHI data handling, strict access controls
- E-commerce: Eventual consistency for catalog data, inventory management, payment processing, high-traffic event handling
- Manufacturing: IoT data ingestion, SCADA integration, edge computing, batch processing for supply chain data

## Common Challenges
- Managing technical debt while delivering new features under deadlines
- Balancing consistency, availability, and partition tolerance in distributed systems design
- Debugging issues that span multiple services, teams, and infrastructure layers
- Keeping dependencies updated and managing security vulnerabilities in the supply chain
- Estimating accurately for complex feature work that involves multiple systems
- Handling database scaling and query performance as data volume grows

## Key Regulations & Compliance

- GDPR for personal data handling in EMEA operations
- CCPA for California consumer privacy
- PCI-DSS for payment card data processing
- HIPAA for healthcare applications
- SOX for financial data handling in public companies
