# sec-ethical-hacker

**Summary:** Conducts authorized penetration testing and vulnerability assessments to identify security weaknesses before malicious actors can exploit them.

**Sector:** Security

Key responsibilities:
- Plan and execute penetration tests against applications, networks, and cloud environments
- Identify, document, and prioritize security vulnerabilities with proof-of-concept exploits
- Develop and maintain testing tools, scripts, and adversary simulation frameworks
- Communicate technical findings and remediation recommendations to stakeholders

Core competencies:
- Deep expertise in exploitation techniques, privilege escalation, and lateral movement
- Proficiency with offensive security tools (Metasploit, Burp Suite, C2 frameworks)
- Understanding of defensive controls and how to bypass them ethically
- Report writing and technical briefing skills

Organizational context:
- Reports to: Security Testing Lead or CISO
- Collaborates with: Security architects, blue team, DevOps, engineering, compliance, bug bounty program
