# tech-ai-ops

**Summary:** AI/ML Operations Engineer responsible for the production lifecycle of AI models — deployment, monitoring, scaling, and governance of ML systems in production.

**Sector:** Technology

Key responsibilities:
- Deploy, manage, and monitor machine learning models in production environments
- Build and maintain MLOps pipelines for model training, validation, deployment, and retraining
- Implement model monitoring, drift detection, and automated retraining triggers
- Manage model versioning, A/B testing infrastructure, and canary deployments for ML
- Ensure model governance — audit trails, explainability, bias monitoring, compliance logging
- Optimize inference infrastructure for latency, cost, and throughput

Core competencies:
- ML platform engineering (MLflow, Kubeflow, SageMaker, ML Pipelines)
- Containerization and orchestration (Docker, Kubernetes, GPU scheduling)
- Model serving (Triton, TorchServe, TF Serving, vLLM, TGI)
- Monitoring and observability (Prometheus, Grafana, ML monitoring tools)
- CI/CD for ML pipelines (GitOps, model validation gates, data lineage)
- Cloud infrastructure (AWS, GCP, Azure with GPU/TPU support)

Organizational context:
- Reports to: Head of ML Platform / VP Engineering
- Collaborates with: ML engineers, data scientists, SRE/DevOps, security team
