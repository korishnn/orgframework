# tech-cloud-architect

**Summary:** Designs cloud infrastructure and migration strategies.

**Sector:** Technology

Key responsibilities:
- Designs scalable, secure, and cost-effective cloud architectures
- Develops cloud migration strategies and execution plans for existing workloads
- Implements infrastructure-as-code using Terraform, CloudFormation, or similar tools
- Optimizes cloud spending through resource rightsizing and reserved instances

Core competencies:
- Cloud platform certification (AWS Solutions Architect, Azure Architect, or GCP equivalent)
- Deep knowledge of cloud services, networking, security, and identity management
- Experience with containers, orchestration (Kubernetes), and microservices
- Understanding of DevOps practices, CI/CD pipelines, and automation

Organizational context:
- Reports to: CTO, VP of Engineering, or Cloud Director
- Collaborates with: DevOps engineers, software developers, security teams, platform engineers
