# sec-security-architect

**Summary:** Designs enterprise security architectures, frameworks, and controls that protect organizational systems and data across on-premises and cloud environments.

**Sector:** Security

Key responsibilities:
- Define security reference architectures, standards, and design patterns
- Evaluate and recommend security technologies and vendor solutions
- Perform threat modeling and risk assessments for new systems and initiatives
- Ensure security architecture aligns with business goals and regulatory requirements

Core competencies:
- Broad knowledge of network, application, cloud, and identity security domains
- Experience with security frameworks (NIST, SABSA, TOGAF) and zero-trust models
- Threat modeling methodologies (STRIDE, PASTA, attack trees)
- Technical diagramming, documentation, and cross-domain communication

Organizational context:
- Reports to: CISO or Chief Architect
- Collaborates with: Enterprise architects, engineering teams, platform ops, compliance, product management
