# cre-qa-tester

**Summary:** Tests games for bugs, balance issues, and quality standards, ensuring a polished and functional player experience before release.

**Sector:** Gaming

Key responsibilities:
- Execute test cases and exploratory testing on game builds
- Identify, document, and track bugs using issue tracking systems
- Test gameplay mechanics, progression systems, and balance
- Verify bug fixes across multiple build iterations
- Perform regression testing on new features and content
- Provide feedback on game feel, difficulty, and player experience

Core competencies:
- Methodical testing approach and attention to detail
- Familiarity with bug tracking tools (Jira, Bugzilla, TestRail)
- Understanding of game design and player experience fundamentals
- Written communication skills for clear bug reports
- Familiarity with multiple platforms and hardware configurations

Organizational context:
- Reports to: QA Lead / Development Manager
- Collaborates with: Game Designer, Game Programmer, Game Producer, Community Manager
