# sport-sports-analyst

**Summary:** Analyzes games and provides commentary for media.

**Sector:** Sports / Media

Key responsibilities:
- Analyzes game footage, statistics, and player performance
- Provides expert commentary and insights for broadcasts
- Writes articles, reports, or segments on sports topics
- Breaks down plays, strategies, and trends for audiences
- Participates in pre-game, post-game, and studio shows

Core competencies:
- Deep sport-specific knowledge and expertise
- Analytical and statistical skills
- Communication and on-camera presence
- Writing and content creation
- Media production and deadline management

Organizational context:
- Reports to: Producer / Sports Director / Editor
- Collaborates with: Commentators, Producers, Journalists, Production Crew
