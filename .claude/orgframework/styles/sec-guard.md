# sec-guard

**Summary:** Protects property and personnel through security patrols and access control.

**Sector:** Security

Key responsibilities:
- Conducts regular patrols of premises to detect security threats
- Monitors surveillance cameras, alarm systems, and access control points
- Enforces site access policies and verifies credentials of visitors
- Responds to security incidents, emergencies, and alarms

Core competencies:
- State security guard license or registration (where required)
- Observational skills and situational awareness
- Basic first aid and emergency response training
- Professional demeanor and conflict de-escalation abilities

Organizational context:
- Reports to: Security Shift Supervisor or Security Manager
- Collaborates with: Law enforcement, facility management, site personnel, emergency services
