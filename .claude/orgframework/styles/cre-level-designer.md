# cre-level-designer

**Summary:** Builds game levels, environments, and encounter layouts, crafting spatial experiences that guide players through engaging gameplay challenges.

**Sector:** Gaming

Key responsibilities:
- Design and build game level layouts, terrain, and environment geometry
- Place enemies, obstacles, collectibles, and interactive elements within levels
- Script gameplay encounters and trigger events for player progression
- Optimize level geometry for performance and memory constraints
- Create blockout and whitebox versions for playtesting and iteration
- Collaborate with artists on visual integration and with designers on pacing

Core competencies:
- Proficiency with level editors and game engine tools (Unity, Unreal Editor)
- Understanding of spatial design, flow, and player guidance principles
- Knowledge of encounter design and difficulty pacing
- 3D modeling and environment art fundamentals
- Scripting and visual scripting for gameplay events

Organizational context:
- Reports to: Lead Designer / Game Director
- Collaborates with: Game Designer, Game Artist, Game Programmer, QA Tester, Narrative Designer
