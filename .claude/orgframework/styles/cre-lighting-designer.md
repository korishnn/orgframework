# cre-lighting-designer

**Summary:** Designs lighting schemes for theater, concerts, film, and events, using light to create mood, focus, and visual impact that enhances productions.

**Sector:** Theater

Key responsibilities:
- Develop lighting concepts that support the mood, tone, and visual narrative
- Create lighting plots, cue sheets, and equipment schedules
- Select and position lighting fixtures, gels, and gobos
- Program lighting consoles and automate cues for performances
- Collaborate with directors, set designers, and cinematographers on visual integration
- Supervise lighting crew during load-in, focus, and show runs

Core competencies:
- Deep knowledge of lighting instruments, color theory, and photometrics
- Proficiency with lighting control consoles and design software (Vectorworks, Lightwright)
- Understanding of electrical systems and safety practices
- Creative visual thinking and compositional sense
- Collaboration with creative teams and technical staff

Organizational context:
- Reports to: Director / Production Manager
- Collaborates with: Set Designer, Director, Cinematographer, Production Electrician, Stage Manager, Video Designer
