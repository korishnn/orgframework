# eng-devops

**Summary:** DevOps Engineer builds and maintains CI/CD pipelines, build systems, developer tooling, and automation that accelerate engineering velocity and improve software delivery reliability.

**Level:** IC
**Reports to:** Director of Infrastructure
**Region variants:** NA, EMEA, APAC, LATAM

## Responsibilities
- Design, implement, and maintain CI/CD pipelines for all engineering teams ensuring fast, reliable software delivery
- Manage build systems, artifact registries, package distribution, and dependency management infrastructure
- Automate infrastructure provisioning and configuration management using infrastructure-as-code practices
- Maintain developer tooling, local development environments, and internal developer productivity tools
- Optimize build times, test execution, and release processes through caching, parallelization, and incremental builds
- Implement security scanning, dependency vulnerability checks, and compliance validation in delivery pipelines
- Document operational runbooks, deployment procedures, and CI/CD standards for the engineering organization
- Manage source control infrastructure, branching strategies, and repository administration
- Monitor CI/CD system health, pipeline performance, and implement alerting for build failures
- Evaluate and integrate new DevOps tools and practices to improve engineering productivity
- Support engineering teams with CI/CD troubleshooting and pipeline optimization
- Drive adoption of DevOps best practices including GitOps, continuous delivery, and infrastructure automation

## Core Competencies
- Expert-level knowledge of CI/CD platforms (GitHub Actions, GitLab CI, Jenkins, Buildkite, CircleCI)
- Strong scripting and automation skills (Bash, Python, Go, or Ruby)
- Deep containerization and orchestration knowledge (Docker, Kubernetes, Helm, Kustomize)
- Infrastructure-as-code expertise (Terraform, Pulumi, Ansible, Chef)
- Understanding of version control strategies, Git workflows, and monorepo management
- Experience with artifact management (Docker Registry, Artifactory, npm, PyPI, Maven)
- Knowledge of cloud platforms and services (AWS, GCP, Azure)
- Familiarity with observability and monitoring tools for CI/CD systems
- Understanding of security scanning and compliance automation in pipelines
- Strong troubleshooting skills across build, test, and deployment failures

## Tools & Technology
- CI/CD: GitHub Actions, GitLab CI, Jenkins, Buildkite, CircleCI, ArgoCD
- Build: Bazel, Gradle, Webpack, Vite, esbuild, Nx, Turborepo
- Containers: Docker, Podman, Kubernetes, Helm, Kustomize, K3s
- IaC: Terraform, Pulumi, Ansible, Chef, Packer
- Artifacts: Docker Registry, Artifactory, Nexus, ECR, GCR, npm registry
- Monitoring: Grafana, Prometheus, Datadog, CloudWatch
- Source: GitHub, GitLab, Bitbucket, Gerrit, Perforce
- Security: Snyk, Trivy, SonarQube, Checkmarx, Dependabot

## KPIs & Success Metrics
- Build time and deployment frequency trends (mean time to deploy)
- CI pipeline pass rate and flaky test rate
- Change failure rate and mean time to recovery
- Developer environment setup time and satisfaction score
- Infrastructure-as-code coverage percentage
- Security vulnerability remediation time from scan results
- CI/CD infrastructure uptime and reliability

## Career Progression
- Junior (0-2 years): Maintains CI/CD pipelines, assists with builds, follows established DevOps practices
- Mid (2-4 years): Owns CI/CD pipeline design, implements automation, manages artifact repositories
- Senior (4-7 years): Architects CI/CD strategy across multiple teams, drives DevOps adoption, mentors engineers
- Staff (7-10 years): Shapes engineering-wide delivery strategy, builds internal developer platforms, influences tooling decisions
- Principal (10+ years): Company-wide DevOps and delivery transformation, defines engineering productivity metrics
- Typical progression: Junior to Mid 1-2 years, Mid to Senior 2-3 years, Senior to Staff 3-4 years

## Day-to-Day Workflow
- Daily standup with infrastructure/platform team to align on priorities
- Monitoring CI/CD pipeline health, investigating failures, and optimizing build performance
- Sprint-based work with 1-2 week iterations, planning and retros aligned with the infrastructure team
- Developer support requests for CI/CD issues, environment problems, and build failures
- Regular security scan reviews and vulnerability remediation coordination
- Weekly 1:1 with manager for career development and workload management
- On-call rotation for CI/CD infrastructure uptime and release support
- Tool evaluation and proof-of-concept work for new DevOps technologies

## Regional Nuances
- NA: Strong Kubernetes and cloud-native DevOps culture; high compensation; emphasis on platform engineering evolution
- EMEA: Growing site reliability engineering overlap with DevOps; strong open-source contribution culture; GDPR considerations for pipeline data
- APAC: Rapid cloud adoption driving DevOps demand in India and Singapore; cost optimization focus; hybrid cloud approaches common
- LATAM: Rising DevOps demand with cloud migration wave; multi-cloud skills valued; time zone advantage for supporting NA teams

## Industry Variations
- SaaS: High-deployment-frequency environments requiring robust CI/CD; canary and blue-green deployment patterns; continuous delivery standard
- Fintech: Compliance-gated deployments; approval workflows in pipelines; segregated build environments for data protection
- Healthcare: HIPAA-compliant CI/CD approaches; change management controls; validation and verification gates in pipelines
- E-commerce: Rapid deployment needs for promotional events; infrastructure scaling automation for traffic spikes
- Manufacturing: Air-gapped deployment scenarios; OT/IT network segmentation; longer release cycles with validation

## Common Challenges
- Balancing developer autonomy with security and compliance requirements in pipelines
- Reducing CI/CD feedback time as codebase and test suite grow
- Managing multi-cloud and hybrid CI/CD infrastructure complexity
- Keeping pace with rapid tooling evolution in the DevOps ecosystem
- Handling dependency vulnerability alerts at scale across many repositories
- Supporting diverse technology stacks and build requirements across teams

## Key Regulations & Compliance
- SOC 2 for change management controls in CI/CD
- SOX for change management in financial systems
- PCI-DSS for build and deployment pipeline security
- FedRAMP for government cloud deployment requirements
- HIPAA for healthcare IT change management
- ISO 27001 for information security in deployment processes
