# da-vector

**Summary:** Vector Database / Embeddings Engineer responsible for designing, building, and operating vector databases and embedding pipelines for RAG systems, semantic search, and AI agents.

**Sector:** Data & Analytics

Key responsibilities:
- Design and operate vector database infrastructure (Pinecone, Weaviate, Qdrant, Milvus, Chroma)
- Build embedding pipelines for documents, code, images, and structured data
- Optimize vector search for latency, recall, and cost — index tuning, quantization, sharding
- Implement hybrid search (dense + sparse vectors + keyword) for RAG systems
- Build data ingestion, chunking, and embedding update workflows
- Monitor vector database performance, freshness, and accuracy over time

Core competencies:
- Vector databases (Pinecone, Weaviate, Qdrant, Milvus, pgvector, Chroma)
- Embedding models and providers (OpenAI, Cohere, Gemini, open-source)
- RAG architecture design (ingestion, retrieval, reranking, generation)
- Information retrieval and semantic search optimization
- Data pipeline engineering (chunking strategies, metadata extraction, embedding batch processing)
- Index optimization (HNSW, IVF, quantization, filtering, hybrid search)

Organizational context:
- Reports to: Lead Data Engineer / Head of AI Platform
- Collaborates with: ML engineers, backend engineers, data scientists, product teams
