# cre-game-programmer

**Summary:** Implements game logic, rendering, physics, and gameplay systems, building the technical foundation that powers interactive experiences.

**Sector:** Gaming

Key responsibilities:
- Implement gameplay features, mechanics, and systems in game engines
- Develop rendering pipelines, graphics features, and visual effects
- Build physics systems, collision detection, and world interaction logic
- Optimize performance for target platforms including memory and frame rate
- Write tools and editor extensions to support the development pipeline
- Debug and fix issues across gameplay, rendering, and networking systems

Core competencies:
- Strong programming skills in C++, C#, or other game development languages
- Proficiency with game engines (Unity, Unreal Engine, custom engines)
- Knowledge of 3D math, linear algebra, and computer graphics
- Understanding of game architecture patterns and optimization techniques
- Debugging and performance profiling expertise

Organizational context:
- Reports to: Lead Programmer / Technical Director
- Collaborates with: Game Designer, Game Artist, QA Tester, Technical Artist, Game Producer
