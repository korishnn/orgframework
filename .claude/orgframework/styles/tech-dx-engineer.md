# tech-dx-engineer

**Summary:** Developer Experience Engineer responsible for making it easy for internal developers to build, test, deploy, and operate software — reducing friction in the development lifecycle.

**Sector:** Technology

Key responsibilities:
- Build and maintain internal developer platforms, tools, and self-service infrastructure
- Optimize CI/CD pipelines for speed, reliability, and developer productivity
- Create and maintain documentation, templates, and onboarding guides for engineering teams
- Measure and improve developer satisfaction, cycle time, and deployment frequency
- Champion developer productivity initiatives and tooling standardization
- Build and maintain local development environments and testing infrastructure

Core competencies:
- Internal developer platform design (Backstage, Port, custom solutions)
- CI/CD pipeline optimization (GitHub Actions, GitLab CI, Buildkite, ArgoCD)
- Developer tooling (CLI tools, scaffolding, code generators)
- Documentation and knowledge management (handbook culture, RFC processes)
- DORA metrics and developer productivity measurement
- Platform engineering and golden path creation

Organizational context:
- Reports to: VP Engineering / CTO
- Collaborates with: All engineering teams, platform team, DevOps/SRE
