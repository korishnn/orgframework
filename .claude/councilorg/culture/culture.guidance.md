# Culture Archetype Overlay

Org structures aren't neutral — they encode culture. This system applies culture overlays to any org structure to show how the same roles work differently under different cultural models.

## Culture Archetypes

### 1. High Trust / Autonomous
- **Structure effect:** Flatter, wider spans of control
- **Decision-making:** Decentralized. Managers set context, not commands.
- **Communication:** Async-first. Direct. Minimal approvals.
- **Typical in:** Tech startups, remote companies, creative agencies, R&D labs
- **When it works:** Expert ICs, self-motivated teams, stable domain
- **When it fails:** High-risk environments, new/inexperienced teams, regulatory pressure
- **Org chart modifiers:** Remove 1-2 management layers, add 2-3 more ICs per manager, dotted lines replace solid lines

### 2. Command & Control
- **Structure effect:** Deeper hierarchy, tighter spans (1:5-7 max)
- **Decision-making:** Centralized. Approvals required at each layer.
- **Communication:** Formal. Chain of command respected. Status reports flow up, decisions flow down.
- **Typical in:** Military, government, manufacturing, banking, large enterprises
- **When it works:** High-risk operations, regulatory environments, standardized processes
- **When it fails:** Creative work, rapid innovation, attracting top talent
- **Org chart modifiers:** Add 1-2 layers, tighten spans, add approval gates at each shift

### 3. Collaborative / Consensus
- **Structure effect:** Matrix reporting, cross-functional pods, many dotted lines
- **Decision-making:** Slow but thorough. Multiple stakeholders consulted. Committees for key decisions.
- **Communication:** Meetings, working groups, alignment documents
- **Typical in:** Scandinavia, academia, nonprofits, European enterprises, design firms
- **When it works:** Complex stakeholder environments, mission-driven orgs, long-term thinking
- **When it fails:** Time-sensitive decisions, competitive pressure, growing fast
- **Org chart modifiers:** Add dotted lines between departments, create cross-functional committees, shared resources between teams

### 4. Meritocratic / Performance-Driven
- **Structure effect:** Flat but competitive. Clear metrics. Tournament promotion model.
- **Decision-making:** Data-driven. Performance metrics determine authority.
- **Communication:** Transparent about performance data. Competitive culture.
- **Typical in:** Consulting firms, investment banks, sales orgs, hedge funds
- **When it works:** Measurable output, competitive individuals, transparent metrics
- **When it fails:** Creative/collaborative work, long-cycle projects, mentoring needs
- **Org chart modifiers:** Add performance review gates between levels, stack-ranking structure, up-or-out timelines

### 5. Caring / Development-Focused
- **Structure effect:** Growth over performance. Mentoring built into spans. Career paths built into roles.
- **Decision-making:** People-first, even at cost of speed. Development plans before assignments.
- **Communication:** Coaching style. Regular 1:1s. 360 feedback.
- **Typical in:** Healthcare, education, social enterprises, religious orgs, family businesses
- **When it works:** People-intensive work, long tenure, mission-driven
- **When it fails:** High-pressure environments, needing rapid restructuring, cost cutting
- **Org chart modifiers:** Add mentoring ratios, career development tracks, reduce spans for manager development time

## Culture Overlay Output

When a user applies a culture overlay:

```
## Culture Overlay: [Structure Name] × [Culture Archetype]

### How This Changes the Structure

| Dimension | Original | With [Culture] Overlay |
|---|---|---|
| Layers | 4 | 3 (flatter) |
| Spans of control | 1:5 | 1:10 (wider) |
| Decision speed | Fast | Decentralized/fast |
| Meeting cadence | Weekly staff | Async + monthly sync |
| Reporting lines | Solid only | Dotted + solid |

### Role Modifications
- **CEO role:** Shifts from command to context-setting
- **Managers:** Shift from supervisors to coaches/leads
- **ICs:** More autonomy, less oversight

### Cultural Practices to Embed
1. [Practice 1] — Reinforces the desired culture
2. [Practice 2] — Prevents cultural drift
3. [Practice 3] — Onboarding for cultural fit

### Potential Friction Points
- [Friction 1] — Between culture overlay and industry norms
- [Friction 2] — Between culture overlay and stage constraints
- [Friction 3] — Between culture overlay and regional expectations
```

## Usage

When a user says "make this more autonomous" or "how would this structure work in a command culture":
1. Load their org structure
2. Apply the selected culture overlay
3. Show what changes in layers, spans, decision-making, communication
4. Identify friction points with their industry/region/stage
5. Recommend cultural practices to embed
