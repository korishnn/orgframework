# tech-tech-writer

**Summary:** Creates technical documentation, user guides, API references, and knowledge base content that makes complex technology accessible to target audiences.

**Sector:** Technology

Key responsibilities:
- Research, outline, write, and edit technical documentation for software and hardware products
- Create API reference documentation, tutorials, and getting-started guides
- Maintain documentation style guides, taxonomies, and information architectures
- Collaborate with subject matter experts to ensure technical accuracy and completeness

Core competencies:
- Exceptional writing, editing, and information design skills
- Ability to understand and explain complex technical concepts clearly
- Proficiency with documentation tools (Markdown, DITA, Sphinx, ReadMe, Docs as Code)
- Familiarity with APIs, SDKs, source code, and developer workflows

Organizational context:
- Reports to: Documentation Manager or Developer Experience Lead
- Collaborates with: Software engineers, product managers, UX designers, support teams, developer relations
