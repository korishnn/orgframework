# eng-qa

**Summary:** Quality Assurance Engineer designs and executes testing strategies, automates quality validation, and champions quality best practices across the software development lifecycle.

**Level:** IC or Manager
**Reports to:** Engineering Manager
**Region variants:** NA, EMEA, APAC, LATAM

## Responsibilities
- Design, develop, and maintain automated test suites covering unit, integration, end-to-end, and visual regression tests
- Create and execute comprehensive manual test plans for new features, regression testing, and exploratory testing
- Identify, document, prioritize, and track defects through resolution in collaboration with development teams
- Implement and maintain CI/CD quality gates that enforce test coverage, performance budgets, and security scan thresholds
- Perform performance, load, and stress testing to validate system behavior under various conditions
- Champion quality best practices across the development lifecycle, promoting shift-left testing approaches
- Define test coverage metrics, track quality trends, and drive continuous improvement initiatives
- Design and maintain test data management strategies including test data generation and environment seeding
- Participate in requirement reviews and provide input on testability and acceptance criteria
- Build and maintain testing frameworks, test harnesses, and testing infrastructure
- Coordinate with cross-functional teams on release readiness and sign-off processes
- Conduct root cause analysis on production defects and drive preventive measures
- Mentor developers in testing best practices and effective test writing

## Core Competencies
- Deep knowledge of testing frameworks, methodologies, and the test automation pyramid
- Strong experience with test automation tools (Selenium, Cypress, Playwright, Appium, WebDriverIO)
- Understanding of CI/CD integration for quality gates and automated test execution
- Familiarity with performance and load testing tools (k6, JMeter, Locust, Gatling)
- Strong analytical debugging skills, root cause analysis, and attention to detail
- Knowledge of agile quality practices including behavior-driven development (BDD) and acceptance test-driven development (ATDD)
- Experience with test case management and defect tracking tools (Jira, TestRail, Xray, Zephyr)
- Understanding of API testing approaches (Postman, REST Assured, Supertest, GraphQL testing)
- Knowledge of mobile testing strategies for iOS and Android platforms
- Familiarity with security testing fundamentals (OWASP Top 10, SAST, DAST)

## KPIs & Success Metrics
- Automated test coverage percentage by code layer (unit, integration, E2E)
- Test pass rate and flaky test rate within CI pipelines
- Defect escape rate (bugs found in production vs. pre-production)
- Mean time to detect and time to resolve quality issues
- Build verification test suite execution time
- Regression test suite execution frequency and duration
- Production incident rate attributable to quality gaps

## Career Progression
- Junior (0-2 years): Writes and maintains automated tests under guidance, executes manual test plans, documents bugs
- Mid (2-4 years): Independently owns test coverage for features, builds test automation frameworks, conducts performance testing
- Senior (4-7 years): Defines test strategy across products, implements test infrastructure, leads quality initiatives
- Lead/Manager (6-10 years): Manages QA team, establishes org-wide quality standards, drives tooling and process improvements
- Director (10+ years): Sets multi-year quality strategy, influences engineering culture, manages quality across multiple teams
- Typical progression: Junior to Mid 1-2 years, Mid to Senior 2-3 years, Senior to Lead 2-4 years

## Day-to-Day Workflow
- Daily standup with engineering team to understand changes in scope and testing priorities
- Test planning aligned with sprint cycles, participating in story grooming to define acceptance criteria
- Continuous test execution monitoring across CI/CD pipelines throughout the day
- Bug triage sessions with developers to prioritize and assign defects
- Test environment coordination with DevOps for test data refreshes and environment stability
- Weekly 1:1 with manager for project priorities and career development
- Performance and load testing cycles aligned with major releases and capacity planning
- Retrospective participation to identify process improvements and quality gaps

## Regional Nuances
- NA: Strong emphasis on automation-first approaches; QA embedded in cross-functional teams; competitive compensation for SDET roles; growing adoption of AI-assisted testing
- EMEA: Greater use of ISTQB certification and formal testing methodologies; stronger labor protections for shift work; works council involvement in Germany
- APAC: Large QA talent pools in India and Philippines; more traditional manual-to-automation transition; cost-effective testing centers of excellence; strong ISTQB certification culture
- LATAM: Growing QA automation market; nearshore testing centers serving US companies; strong community in Brazil; Portuguese and Spanish language capabilities valuable

## Industry Variations
- SaaS: Continuous delivery requires fully automated regression suites; multi-tenant testing complexity; API contract testing critical; browser compatibility testing
- Fintech: Regulatory compliance testing required (SOX, PCI-DSS); transaction integrity testing; security testing integrated into QA workflows; audit trail validation
- Healthcare: HIPAA compliance validation; clinical workflow testing; integration testing with HL7/FHIR standards; patient data privacy testing
- E-commerce: Cart and checkout flow testing; payment gateway integration testing; inventory accuracy validation; mobile app testing for shopping experiences

## Common Challenges
- Keeping test suites reliable and fast as the product grows in complexity
- Balancing automated coverage investment with manual exploratory testing value
- Managing flaky tests that erode confidence in the CI/CD pipeline
- Getting sufficient test environment access and stable test data
- Coordinating testing across multiple platforms, browsers, and device configurations
- Communicating quality risks to product management without being seen as a blocker

## Key Regulations & Compliance
- ISO 9001 for quality management systems
- ISO 25000 for software quality requirements and evaluation
- SOC 2 for service organization controls affecting testing requirements
- FDA 21 CFR Part 820 for software in medical devices
- PCI-DSS for payment application testing requirements
- GDPR for data protection impact assessments including testing data
