# tech-ai-engineer

**Summary:** Develops AI and machine learning models, pipelines, and production systems that deliver intelligent capabilities at scale.

**Sector:** Technology

Key responsibilities:
- Design, train, evaluate, and deploy machine learning models for business use cases
- Build data pipelines, feature stores, and MLOps infrastructure
- Monitor model performance, drift, and retrain as needed in production
- Research and integrate state-of-the-art AI techniques and foundation models

Core competencies:
- Proficiency in ML frameworks (PyTorch, TensorFlow, JAX) and model deployment
- Data engineering, feature engineering, and experiment tracking
- MLOps: CI/CD for models, containerization, model serving, A/B testing
- Mathematical foundations: linear algebra, statistics, optimization

Organizational context:
- Reports to: AI Engineering Manager, Head of ML, or CTO
- Collaborates with: Data scientists, software engineers, product managers, data engineers, infrastructure teams
