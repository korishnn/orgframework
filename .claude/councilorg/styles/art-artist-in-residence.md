# art-artist-in-residence

**Summary:** Creates art while embedded in a host institution or community.

**Sector:** Arts and Culture

Key responsibilities:
- Produce original artworks in a dedicated studio space provided by the host organization
- Engage with the host community through workshops, open studios, or public talks
- Document creative process and present work in a culminating exhibition or performance
- Contribute to the host's cultural programming and public engagement goals

Core competencies:
- Demonstrated artistic skill and a coherent creative practice across chosen media
- Ability to work independently and adapt practice to an unfamiliar institutional environment
- Communication and facilitation skills for public engagement and educational activities
- Self-direction in managing project timelines, materials, and deliverables

Organizational context:
- Reports to: Residency coordinator, curatorial director, or program manager
- Collaborates with: Host institution staff, other resident artists, community partners, and visiting critics
