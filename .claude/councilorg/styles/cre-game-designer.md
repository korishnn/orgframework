# cre-game-designer

**Summary:** Designs game mechanics, systems, and player experiences, defining rules, interactions, and progression that make games engaging and fun.

**Sector:** Gaming

Key responsibilities:
- Design core game mechanics, rules, and reward systems
- Create game design documents and system specifications
- Prototype and iterate on gameplay features and interactions
- Balance game difficulty, progression, and economy systems
- Collaborate with artists, programmers, and producers on implementation
- Conduct playtests and analyze player feedback to refine designs

Core competencies:
- Deep understanding of game design principles and player psychology
- Systems thinking and mathematical modeling for game balance
- Proficiency with game engines (Unity, Unreal) and scripting
- Analytical skills for data-driven design decisions
- Creative problem-solving and iterative design methodology

Organizational context:
- Reports to: Game Director / Creative Director
- Collaborates with: Level Designer, Game Programmer, Game Artist, Game Producer, Narrative Designer, QA Tester
