# ops-it

**Summary:** Provides internal IT support, endpoint device management, enterprise application administration, and IT infrastructure operations that enable employee productivity and secure technology access.

**Level:** Manager or IC
**Reports to:** Director of IT / COO
**Region variants:** NA, EMEA, APAC, LATAM

## Responsibilities
- Provide tiered IT support (Tier 1-3) for employees including hardware troubleshooting, software issues, network connectivity, and account access problems.
- Manage the complete device lifecycle including procurement, provisioning, imaging, configuration, deployment, maintenance, and secure decommissioning.
- Administer enterprise SaaS applications including email and calendar (Google Workspace or Microsoft 365), identity management (Okta, Azure AD), collaboration tools (Slack, Teams, Zoom), and productivity suites.
- Maintain IT asset inventory including hardware, software licenses, SaaS subscriptions, and cloud service accounts with accurate lifecycle tracking.
- Implement and enforce IT security policies including acceptable use, password management, multi-factor authentication, device encryption, and remote access controls.
- Manage user account lifecycle including onboarding creation, access permissions, role changes, and offboarding deprovisioning across all enterprise systems.
- Deploy and manage endpoint protection including antivirus, endpoint detection and response (EDR), mobile device management (MDM), and patch management.
- Manage local area network (LAN), wireless (Wi-Fi), and VPN infrastructure to ensure reliable connectivity across all office locations and remote workers.
- Support audio/visual systems in conference rooms including Zoom Rooms, Microsoft Teams Rooms, and presentation equipment.
- Manage IT procurement including hardware purchasing, software licensing negotiations, and vendor relationship management for IT products and services.
- Develop and maintain IT documentation including knowledge base articles, technical guides, onboarding checklists, and system architecture diagrams.
- Participate in IT incident response for security events, system outages, and service disruptions, following the incident management process.
- Manage backup and disaster recovery for critical IT systems, ensuring data integrity and recovery capability.
- Support corporate applications including HRIS, ERP, CRM, expense management, and other enterprise systems through integration and user support.

## KPIs & Success Metrics
- Ticket resolution time: average time from ticket creation to resolution
- First contact resolution rate: percentage of tickets resolved at Tier 1 without escalation
- Employee satisfaction with IT support: post-resolution CSAT survey score
- Ticket volume trends: tickets per employee per month across categories
- Device provisioning time: average hours from order to fully configured device
- System uptime: percentage uptime for critical IT systems (email, identity, network)
- Software license compliance: percentage of software usage covered by active licenses
- Security patch compliance: percentage of managed devices with current security patches

## Career Progression
- Entry level: IT Support Specialist / Help Desk Technician handling Tier 1 tickets, device provisioning, and account setup under supervision.
- Mid level: IT Administrator or System Administrator managing enterprise systems, identity administration, and Tier 2/3 support.
- Senior level: Senior IT Engineer or IT Manager overseeing IT operations, leading projects, managing the help desk team, and driving improvements.
- Lead level: IT Operations Manager or Infrastructure Manager managing the entire IT operations function, strategy, and team.
- Director level: Director of IT owning the full IT function, technology strategy, budget, and IT governance.
- VP level: VP of IT or CIO responsible for enterprise technology strategy and digital workplace transformation.
- Timeline: 1-2 years as support specialist, 2-3 years as administrator, 2-3 years as senior/lead, then manager/director track.

## Day-to-Day Workflow
- Morning: Review help desk tickets submitted overnight, prioritize urgent issues (outages, executive escalations, security incidents), resolve high-priority tickets, check system health dashboards.
- Midday: On-site device provisioning for new hires, walk-in support for urgent employee issues, ticket work across Tier 1-3 queue, system administration tasks.
- Afternoon: Project work on IT initiatives (system upgrades, software rollouts, security improvements), documentation updates, vendor communication for procurement or support.
- Weekly: IT team standup, onboarding batch processing, patch deployment maintenance window, knowledge base review and updates.
- Monthly: Software license audit and reconciliation, IT budget tracking, security report review (phishing simulation results, patch compliance), asset inventory verification.
- Quarterly: IT projects review and planning, vendor performance reviews, security policy review, disaster recovery testing, technology refresh planning.
- Annual: IT budget planning, hardware refresh cycle execution, technology roadmap update, IT audit support, vendor contract renewals.
- Rhythms: Help desk tickets create a steady operational flow with typical peaks Monday mornings and post-holiday. New hire start dates create predictable provisioning spikes. Quarterly and annual planning cycles drive project work cadence.

## Regional Nuances
- NA: Mac-heavy environment in tech companies (higher cost but user preference). Cloud-first approach with minimal on-premise infrastructure. Remote work has driven VPN and Zero Trust architecture adoption. 24/7 support is common. Strong focus on employee self-service and automation.
- EMEA: GDPR compliance significantly impacts IT operations (data processing records, right to erasure, data retention). Works council involvement in employee monitoring and IT system changes in Germany, France, Netherlands. Language support requirements in multi-language environments. Stronger on-premise legacy infrastructure in some industries.
- APAC: Time zone coverage requires distributed support teams. Language support for local languages is essential. China's Great Firewall requires specific VPN arrangements and hosted services within China. India has a large, cost-effective IT talent pool for shared service centers. Infrastructure quality varies significantly.
- LATAM: Internet connectivity quality varies across markets, affecting remote work capability. IT hardware import restrictions in some countries affect procurement. Local support in Portuguese (Brazil) and Spanish is required. Infrastructure investment is generally lower than in NA/EMEA. Cloud adoption is growing but on-premise still common.

## Industry Variations
- SaaS: Dogfooding internal use of the company's own product. Heavy automation of IT processes using internal tools. Engineering-adjacent IT culture with strong DevOps collaboration. BYOD policies are more flexible. Remote-first IT operations for distributed teams.
- Fintech: Enhanced security controls for regulated environments. Strict change management and access control processes. Regulatory compliance drives IT audit requirements. Monitoring and logging requirements are extensive. Role-based access control with segregation of duties.
- Healthcare: HIPAA compliance governs all IT operations. Medical device integration requires specialized support. Bio-medical IT support for clinical systems. 24/7 support for hospital IT operations. Strong access controls for patient data systems.
- Manufacturing: OT (operational technology) and IT convergence requires specialized support. Shop floor IT support for manufacturing execution systems (MES). SCADA and control system integration. Heavy reliance on Windows in industrial environments. Shift-based support coverage for 24/7 operations.
- E-commerce: High-traffic peak event support (Black Friday, Prime Day). Fulfillment center IT support (scanners, label printers, sortation systems). Rapidly scalable support for seasonal workforce surges. Point-of-sale and retail technology support for physical stores.

## Common Challenges
- Managing the tension between security controls and employee productivity (restrictive vs. permissive IT).
- Supporting a diverse technology environment across multiple operating systems, device types, and mobile platforms.
- Keeping up with SaaS application sprawl as departments independently adopt tools without IT involvement.
- Managing device lifecycle and data security for a fully remote workforce with no return-to-office requirement.
- Maintaining service quality during rapid headcount growth when provisioning and support must scale quickly.
- Budget constraints for hardware refresh cycles and technology upgrades in cost-conscious periods.

## Key Regulations & Compliance
- US: SOX ITGC (IT general controls) over financial systems, HIPAA technical safeguards for healthcare, state data breach notification laws, COPPA for child-related data, FTC Safeguards Rule for financial data, CCPA/CPRA for California employee and consumer data, GLBA for financial services.
- UK: UK GDPR and Data Protection Act 2018, Privacy and Electronic Communications Regulations (PECR), Network and Information Systems (NIS) Regulations, Computer Misuse Act 1990, Telecommunications Security Code.
- EU: GDPR (data processing, breach notification, data portability, right to erasure), ePrivacy Directive for electronic communications, NIS2 Directive for network and information security, EU Cybersecurity Act, country-specific IT security laws (Germany BSI Gesetz, France LPM).
- Canada: PIPEDA (privacy and data handling), provincial privacy laws (PIPA in AB, BC, QC), Canada's Anti-Spam Legislation (CASL), Personal Health Information Protection Act (PHIPA) in Ontario.
- Brazil: LGPD data protection and processing requirements, Marco Civil da Internet (internet governance and data retention), ANPD (National Data Protection Authority) regulations and guidelines for security measures and data processing.
- Australia: Privacy Act 1988 and Australian Privacy Principles (APPs), Notifiable Data Breaches (NDB) scheme, Telecommunications Act 1997 interception provisions, SOCI Act (Security of Critical Infrastructure Act 2018) for critical infrastructure, state-based privacy laws.
