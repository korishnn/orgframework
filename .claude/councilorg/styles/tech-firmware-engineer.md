# tech-firmware-engineer

**Summary:** Develops firmware for hardware devices and IoT systems, bridging low-level hardware control with higher-level application logic.

**Sector:** Technology

Key responsibilities:
- Design and implement firmware for microcontrollers, SoCs, and connected devices
- Develop communication protocol stacks (I2C, SPI, UART, BLE, Wi-Fi, Zigbee)
- Implement over-the-air update mechanisms and device lifecycle management
- Perform hardware-software integration testing and debug at the system level

Core competencies:
- Strong C and C++ skills for resource-constrained environments
- Experience with wireless protocols, IoT platforms, and connectivity stacks
- Knowledge of bootloaders, memory management, and low-power design
- Version control, CI/CD for firmware, and automated testing of embedded systems

Organizational context:
- Reports to: Firmware Engineering Manager or Embedded Systems Lead
- Collaborates with: Embedded engineers, hardware engineers, cloud/backend engineers, QA, product management
