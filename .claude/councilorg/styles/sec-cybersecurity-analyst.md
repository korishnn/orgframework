# sec-cybersecurity-analyst

**Summary:** Monitors, detects, and responds to security threats and incidents to protect an organization's information systems and data.

**Sector:** Security

Key responsibilities:
- Monitor security alerts and logs from SIEM, EDR, and network detection tools
- Triage and investigate potential security incidents and escalate as needed
- Document incident findings, remediation steps, and post-incident reports
- Maintain and tune detection rules and security monitoring infrastructure

Core competencies:
- Knowledge of network protocols, operating systems, and common attack vectors
- Hands-on experience with SIEM, EDR, and threat intelligence platforms
- Analytical thinking and root-cause analysis under pressure
- Clear incident documentation and communication

Organizational context:
- Reports to: Security Operations Manager or Incident Response Lead
- Collaborates with: IT operations, threat intelligence team, system administrators, engineering, compliance
