# tech-sys-admin

**Summary:** Administers servers, systems, and IT infrastructure.

**Sector:** Technology

Key responsibilities:
- Installs, configures, and maintains server operating systems and software
- Manages user accounts, permissions, and directory services
- Performs system backups, disaster recovery testing, and patch management
- Monitors system health, performance, and security across the infrastructure

Core competencies:
- System administration experience with Windows Server, Linux, or cloud platforms
- Knowledge of virtualization, storage, and backup technologies
- Scripting and automation skills (PowerShell, Bash, Python)
- Understanding of IT security best practices and disaster recovery

Organizational context:
- Reports to: IT Manager or Infrastructure Director
- Collaborates with: Network administrators, security teams, help desk, application owners
