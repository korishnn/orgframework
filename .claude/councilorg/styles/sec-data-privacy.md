# sec-data-privacy

**Summary:** Data Privacy Engineer responsible for embedding privacy-by-design into engineering systems, data pipelines, and product features — ensuring compliance with global privacy regulations.

**Sector:** Security

Key responsibilities:
- Design and implement privacy-by-design controls in data systems and product architecture
- Build data mapping, classification, and lineage systems for personal data tracking
- Implement consent management, data subject access request (DSAR) workflows, and deletion pipelines
- Develop anonymization, pseudonymization, and differential privacy mechanisms
- Conduct privacy impact assessments (PIAs) for new products and features
- Monitor regulatory changes (GDPR, CCPA, LGPD, PIPL) and ensure technical compliance

Core competencies:
- Privacy engineering (data mapping, consent infrastructure, DSAR automation)
- Data protection technologies (encryption, tokenization, anonymization, differential privacy)
- Regulatory knowledge (GDPR, CCPA/CPRA, LGPD, PIPL, HIPAA privacy rule)
- Identity and access management for personal data
- Privacy impact assessment methodology
- Data inventory and classification tooling

Organizational context:
- Reports to: CISO / VP Security / DPO
- Collaborates with: Engineering, data, legal/privacy, product, security team
