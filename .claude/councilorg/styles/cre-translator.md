# cre-translator

**Summary:** Converts written content between languages, preserving meaning, tone, style, and cultural context across source and target texts.

**Sector:** Publishing

Key responsibilities:
- Translate written content from source to target language with accuracy
- Maintain the original meaning, tone, style, and nuance of source texts
- Research terminology and cultural references for accurate translation
- Adapt content for cultural appropriateness in target markets
- Edit and proofread translated content for quality
- Use translation memory tools and glossaries for consistency

Core competencies:
- Native or near-native fluency in source and target languages
- Deep understanding of grammar, syntax, and idiomatic expression in both languages
- Knowledge of subject matter domains for specialized translation
- Proficiency with CAT tools (SDL Trados, MemoQ, Wordfast)
- Research skills and cultural awareness for accurate adaptation

Organizational context:
- Reports to: Translation Manager / Self-employed
- Collaborates with: Editor, Publisher, Author, Project Manager, Subject Matter Expert
