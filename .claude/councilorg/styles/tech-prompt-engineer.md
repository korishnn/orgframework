# tech-prompt-engineer

**Summary:** Prompt Engineer / LLM Interaction Designer responsible for designing, testing, and optimizing prompts and interaction patterns for large language models across products and workflows.

**Sector:** Technology

Key responsibilities:
- Design and optimize prompts for LLM-powered features across products
- Build prompt templates, chains, and workflows (few-shot, chain-of-thought, ReAct, RAG patterns)
- Develop prompt versioning, testing, and evaluation frameworks
- Conduct systematic prompt experiments to improve accuracy, safety, and reliability
- Build guardrails, content filters, and safety mechanisms for LLM outputs
- Collaborate with product and engineering to integrate LLM capabilities effectively

Core competencies:
- Advanced prompt engineering techniques (chain-of-thought, tree-of-thought, structured outputs)
- LLM evaluation and red-teaming methodologies
- RAG architecture and retrieval optimization
- Prompt versioning and CI/CD for prompts
- Understanding of model capabilities, limitations, and failure modes
- API integration with OpenAI, Anthropic, open-source models

Organizational context:
- Reports to: Head of AI / AI Engineering Manager
- Collaborates with: Product managers, software engineers, AI safety team, UX designers
