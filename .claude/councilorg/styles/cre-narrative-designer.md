# cre-narrative-designer

**Summary:** Crafts story, dialogue, and world-building within games, integrating narrative elements with interactive gameplay systems.

**Sector:** Gaming

Key responsibilities:
- Write branching narratives, dialogue trees, and character stories
- Develop game lore, world-building documents, and faction histories
- Create quest outlines, mission briefs, and narrative content
- Collaborate with game designers to integrate story with gameplay mechanics
- Write in-game text including item descriptions, codex entries, and UI copy
- Implement narrative content using game engine scripting tools

Core competencies:
- Strong creative writing and dialogue crafting ability
- Understanding of interactive storytelling and branching narrative design
- Knowledge of game design principles and player agency concepts
- Familiarity with narrative scripting tools and dialogue systems
- World-building and lore development skills

Organizational context:
- Reports to: Creative Director / Lead Writer
- Collaborates with: Game Designer, Level Designer, Game Artist, Game Programmer, Voice Actor, Audio Designer
