# cre-game-artist

**Summary:** Creates visual assets including characters, environments, props, and textures that define the aesthetic of video games.

**Sector:** Gaming

Key responsibilities:
- Create 2D and 3D art assets including characters, environments, and props
- Model, texture, and UV-map 3D assets for real-time rendering
- Paint concept art, color keys, and environment mood boards
- Create character rigs and prepare assets for animation
- Optimize art assets for performance within engine constraints
- Maintain visual consistency with the game's art direction and style

Core competencies:
- Proficiency with 3D modeling software (Maya, Blender, 3ds Max, ZBrush)
- Strong understanding of anatomy, perspective, color theory, and composition
- Knowledge of texturing tools (Substance Painter, Photoshop) and PBR workflows
- Familiarity with game engines and real-time rendering limitations
- Concept art and visual development skills

Organizational context:
- Reports to: Art Director / Lead Artist
- Collaborates with: Game Designer, Animator, Technical Artist, Level Designer, Art Director
