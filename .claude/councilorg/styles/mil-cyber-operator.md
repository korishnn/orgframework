# mil-cyber-operator

**Summary:** Conducts offensive and defensive cyber operations for the military to protect networks and systems.

**Sector:** Military

Key responsibilities:
- Conducts network penetration testing and vulnerability assessments
- Defends military networks against cyber attacks and intrusions
- Develops and executes offensive cyber operations
- Analyzes malware and threat actor tactics and procedures
- Implements cybersecurity tools and security measures

Core competencies:
- Network security and intrusion detection
- Operating systems and system administration
- Scripting and programming languages
- Cyber threat intelligence and analysis
- Ethical hacking and exploitation methodologies

Organizational context:
- Reports to: Cyber Operations Officer or Section Chief
- Collaborates with: Intelligence Analysts, IT Staff, Joint Cyber Units, National Security Agencies
