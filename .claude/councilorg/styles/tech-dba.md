# tech-dba

**Summary:** Manages databases, performance, security, and backups.

**Sector:** Technology

Key responsibilities:
- Designs, implements, and maintains database schemas and structures
- Optimizes query performance and indexes for application efficiency
- Manages database security, access controls, and encryption
- Performs backups, recovery testing, and migration between environments

Core competencies:
- Proficiency with SQL and database management systems (Oracle, SQL Server, MySQL, PostgreSQL)
- Knowledge of database design, normalization, and data modeling
- Understanding of backup, recovery, and high-availability strategies
- Performance tuning and query optimization skills

Organizational context:
- Reports to: Data Engineering Manager or IT Director
- Collaborates with: Developers, data analysts, system administrators, application teams
