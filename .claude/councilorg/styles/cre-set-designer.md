# cre-set-designer

**Summary:** Designs and oversees construction of theatrical sets, creating physical environments that support storytelling and directorial vision.

**Sector:** Theater

Key responsibilities:
- Develop scenic designs based on script analysis and directorial concept
- Create scale models, renderings, and technical drawings of set designs
- Select materials, textures, and construction methods for sets
- Oversee set construction, painting, and finishing in the scene shop
- Collaborate with lighting and costume designers for visual cohesion
- Manage set budgets and construction timelines

Core competencies:
- Strong drafting, drawing, and 3D modeling skills
- Knowledge of construction techniques, materials, and stage mechanics
- Understanding of theatrical storytelling and spatial design
- Collaboration with directors and production teams
- Budget management and project scheduling abilities

Organizational context:
- Reports to: Director / Production Manager
- Collaborates with: Director, Costume Designer, Lighting Designer, Technical Director, Scene Shop Staff, Props Master
